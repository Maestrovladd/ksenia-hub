# «Легче, Кисуль!» — пакет переноса лендинга на GetCourse

**Для технического специалиста.** Этот пакет переносит существующий визуальный лендинг, а не создаёт его заново из стандартных блоков GetCourse. Исходный лендинг на GitHub не менять. Отдельно проверить GetCourse на тестовой неопубликованной странице до замены продающей ссылки.

## 1. Что в пакете

| Файл | Назначение | Куда |
|---|---|---|
| `fragment.html` | Вся разметка лендинга, изображения, отзывы, футер, демонстрационный диалог | Один блок «Вставка → HTML» |
| `styles.css` | Исходная стилистика со **строгим ограничением селекторов** внутри `#ks-marathon`, адаптивность, мягкие эффекты | Подключить ссылкой из блока CSS / HEAD страницы |
| `interactive.js` | Кнопки заказа, перелистывание отзывов, появление блоков, мобильная кнопка, взаимодействие с формой | В «Вставка → Javascript-код» или через подключение скрипта |
| `preview.html` | Автономный предпросмотр переноса | Открыть для визуального сравнения (GitHub Pages) |
| `assets/` | **20 исходных изображений**, включая все опубликованные отзывы; структура и оригинальные имена файлов сохранены | Загрузить в файлы GetCourse, заменить ссылки по карте ниже |
| `asset-manifest.json` | Полный реестр изображений и размеры | Контроль переноса |
| `README_FOR_TECH.md` | Эта инструкция | Для исполнителя |

**Важное исключение:** двоичные шрифтовые файлы в комплекте не передаются. Сейчас код подключает исходные Inter и Tenor Sans с публичного домена GitHub Pages. При необходимости независимого размещения в GetCourse согласовать с владельцем исходные лицензированные файлы шрифтов и их легальное размещение. Не заменять шрифты на Arial по умолчанию.

## 2. Что сохраняется из оригинала

- Все исходные тексты, изображения, цены и расположение секций.
- Типографика: Tenor Sans для заголовков и Inter для основного текста, исходные letter-spacing и line-height из CSS.
- Сетка: `wrap` до 1240px, десктопные отступы, медиазапросы, мобильные композиции исходного сайта.
- Отзывы — горизонтальное листание; на смартфоне swipe и scroll-snap.
- Дополнения: лёгкий hover карточек, движение стрелок кнопок, мягкое появление блоков по скроллу, нижняя мобильная CTA, доступные фокусы, уменьшение эффектов при prefers-reduced-motion.
- Pop-up — ограничен по высоте экрана, внутренний скролл, закрытие Escape и по крестику; **демонстрационная** форма намеренно не отправляет данные.

Не пытаться усиливать все карточки одновременно: hover только у интерактивных/смысловых карточек; на телефоне нет hover-скачков. Не использовать тяжёлые параллаксы, карусели там, где можно прокрутить вертикально, или анимацию каждого предложения.

## 3. Перенос на GetCourse — по шагам

### Шаг 1. Создать отдельную тестовую страницу

1. GetCourse → **Сайт → Страницы** → создать новую страницу (например, «Марафон / тест переноса»). Не редактировать работающую страницу.
2. Использовать **чистый шаблон без системной шапки, подвала и бокового меню**, если они уже есть: на лендинге предусмотрены свои блоки.
3. В настройках страницы при необходимости отключить встроенные шрифты по умолчанию и стили по умолчанию; это возможно в GetCourse для собственного дизайна, но не меняйте глобальные темы всей школы.
4. Проверить, чтобы у общего блока не было добавленных GetCourse полей `padding-left/right`, максимальной ширины, фоновой подложки. Сам лендинг имеет собственную ширину и интервалы.
5. Запретить индексацию тестовой страницы до приемки.

### Шаг 2. Подключить CSS без конфликта с GetCourse

CSS = ~85 КБ, поэтому **не нужно вставлять его в короткое поле темы с лимитом символов**. Удобнее подключить внешний файл (из временного GitHub хостинга) в раннем HTML-блоке:

```html
<link rel="stylesheet" href="https://maestrovladd.github.io/ksenia-hub/getcourse-transfer/styles.css?v=1">
```

Альтернативный путь: в **«Вставка → CSS-код»** разместить:

```css
@import url('https://maestrovladd.github.io/ksenia-hub/getcourse-transfer/styles.css?v=1');
```

CSS намеренно начинается с `#ks-marathon` и не должен менять оформление соседних элементов GetCourse. Для независимого хостинга загрузить `styles.css` и заменить URL на адрес файла GetCourse.

### Шаг 3. Вставить HTML целиком

1. Добавить блок **«Вставка → HTML»**.
2. Открыть `fragment.html`. Скопировать весь текст файла и вставить **без** обрамления `<html><head><body>` — это уже готовый фрагмент страницы.
3. Вставить блок на всю ширину страницы.
4. Убедиться, что верхний div имеет `id="ks-marathon"` и существует единственный `id="enroll-dialog"`.
5. Если GetCourse удаляет часть HTML внутри своего редактора, используйте альтернативную вставку HTML как код и проверяйте фактический DOM в предпросмотре.

### Шаг 4. Подключить JS

Добавить **«Вставка → Javascript-код»** ниже HTML. Вставить содержимое `interactive.js` без внешних тегов `<script>` (если поле ожидает чистый JS). Или подключить:

```html
<script defer src="https://maestrovladd.github.io/ksenia-hub/getcourse-transfer/interactive.js?v=1"></script>
```

Не дублировать оба способа. Скрипт защищён от повторного запуска, но лишние подключения ухудшают дебаг.

### Шаг 5. Подключить **реальный** заказ и оплату

**Критически важно:** в ZIP оставлен **нерабочий демонстрационный макет формы**: поля в нём отключены. Он нужен, чтобы проверить вид, фокус и прокрутку. Никакая оплата в макете не проходит.

Предпочтительный способ для GetCourse:
1. Создать продукт и **предложение на 2 000 ₽** с корректными условиями 14 дней + 7 дополнительных дней доступа.
2. Создать штатную **форму продажи** GetCourse: Имя, Фамилия (если действительно требуется), Email (обязателен), Телефон (по необходимости); согласия на документы. Настроить обработчик **«Создать заявку / заказ»**, привязать нужное предложение, оплату и действие после оплаты.
3. Включить форму как **всплывающий блок** и создать штатную кнопку/триггер GetCourse **на той же странице**, который её открывает. Рекомендуется дать этой кнопке CSS ID `gc-native-order-trigger` или согласовать любой другой стабильный селектор.
4. В **отдельном JS-блоке до** `interactive.js` прописать:

```js
window.KSENIA_GC = {
  nativePopupTriggerSelector: '#gc-native-order-trigger'
};
```

После этого **все наши кнопки** `data-enroll` будут открывать **настоящий поп-ап** GetCourse через его триггер. Демонстрационный диалог перестанет открываться.
5. Оформить **сам штатный поп-ап GetCourse** в той же палитре и типографике. У GetCourse могут быть отличающиеся внутренние классы; сначала проверить DOM формы, затем задать только её индивидуальные стили. Не применять глобальный CSS ко всем формам школы.
6. Для нативного модального окна проверить `max-height:calc(100dvh - 24px)`, `overflow-y:auto`, место под safe-area и возможность скролла при открытой мобильной клавиатуре. Это **отдельная проверка**, потому что CSS нашего демонстрационного диалога не управляет нативным поп-апом GetCourse.
7. Протестировать создание оплаченного заказа и доступ в тренировочную программу. Не публиковать кнопки «Купить», пока нет успешного теста.

Штатные формы GetCourse поддерживают создание и оплату заказа, а всплывающий блок может открываться с кнопки на этой же странице. Официальные инструкции:
- https://getcourse.ru/blog/275809
- https://getcourse.ru/blog/275829
- https://getcourse.ru/blog/275808

### Шаг 6. Перенести 20 изображений

В архиве есть `assets/` с исходными именами файлов. Для загрузки можно воспользоваться **«Файлы» GetCourse** или подходящим загрузчиком медиа страницы. После загрузки:
- Найти в `fragment.html` все вхождения `https://maestrovladd.github.io/ksenia-hub/landing/assets/`.
- Заменить адрес каждого файла на **его опубликованный путь GetCourse**, сохранив `alt`, размеры, пропорции и изображения отзывов.
- Найти в `styles.css` все ссылки `https://maestrovladd.github.io/ksenia-hub/landing/assets/` и заменить только те, которые ведут на картинки (если есть).
- Сверить визуально фото героя, Ксюши, блюда (вафли, суп, ужин, перекус), фотографии в секциях, 7 отзывов.
- Проверить запросы в Network браузера: ни одного 404.

### Шаг 7. Довести юридические ссылки и детали

**В исходном лендинге юридические документы в подвале обозначены текстом, а не кликабельными ссылками.** Перед публикацией сделать реальные `<a href="...">` для политики, оферты и необходимых согласий; не придумывать их URL. В форме также должны быть реальные ссылки и требуемые согласия.

Проверить актуальность цены, фамилии Ксении, данных исполнителя, состава 8 занятий и четырёх рационов. Сверить с финальной офертой.

## 4. Проверка адаптивности (не пропускать)

| Экран | Что смотреть |
|---|---|
| 320px | Нет горизонтального скролла всей страницы, не обрезан заголовок, доступен pop-up |
| 360px | Первая кнопка видна без лишних прокруток, карточки в одну колонку |
| 375px / 390px | Нет наложений кнопки на контент, отзывы листаются пальцем |
| 430px | Карточки, иллюстрации и тексты не разъезжаются |
| 768px | Точка перехода мобильной сетки в планшетную |
| 1024px | Отступы, ширина фото и заголовков без случайных переносов |
| 1280 / 1440px | Выдержаны интервалы оригинала |
| 1920px | Фон по ширине экрана, контент остаётся ограниченным по сетке |

**На каждой ширине:** скриншоты первого экрана, секции преимуществ, состава марафона, расписания, отзывов, стоимости, открытого поп-апа.

Проверить Safari iOS и Chrome Android (минимум по одному реальному устройству), desktop Chrome/Safari. Повернуть телефон, проверить 200% системное увеличение текста.

## Исправление от 31 октября 2026: тёмный блок «Этот марафон для тебя, если…»

**Что было:** секция одновременно имела классы `audience` и `wrap`. Класс `wrap` ограничивал ширину самого тёмного фона, а `audience` размещал содержимое без внутренних боковых отступов. В результате по краям были светлые полосы, а заголовок и пункты списка могли выглядеть обрезанными. Это дефект подготовленной верстки, не ошибка GetCourse и не результат того, что файл открыт локально.

**Что исправлено:** в `styles.css` добавлено правило для `#ks-marathon :is(.audience,.philosophy,.stories,.benefits).wrap` — тёмные секции расширены по ширине, сохранена исходная двухколоночная композиция на десктопе и введены адаптивные горизонтальные отступы для мобильных устройств. Исходный лендинг `landing/` не меняли.

**Дополнительная проверка структуры:** найдены другие тёмные секции с тем же сочетанием классов `wrap` + фоновый цвет — `philosophy`, `stories` и запасная `benefits`. Аналогичное правило применено и к ним.

**Проверка:** отдельную проблемную секцию воспроизвели в Chromium на ширинах 320 / 360 / 390 / 644 / 768 / 960 / 1024 / 1280 / 1440 px, проверили координаты границ и отсутствие горизонтального скролла. Это проверка **секции на изолированном макете**, а не полная приемка перенесенной страницы в GetCourse. Проверить всю страницу визуально после установки кода всё равно обязательно.

**Если у вас уже скачан старый ZIP:** замените `styles.css` новой версией либо скачайте комплект заново на странице `https://maestrovladd.github.io/ksenia-hub/getcourse-transfer/`. `preview.html` в репозитории теперь использует `styles.css?v=4` для обхода кеширования.
