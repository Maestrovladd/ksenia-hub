# Техническому специалисту — собираем «Легче, Кисуль!» в GetCourse

**Единственная актуальная логика (01.11.2026):** [см. окончательный маршрут](./FINAL_ROUTE_2026-10-31.md). Основа — файл заказчика «Оплата — сайт.docx». Логику с тремя вступительными уроками **не использовать**.

## Начало: оплата и два урока

**После покупки за 2 000 ₽** показать страницу благодарности и отправить email со входом на платформу. Готовые тексты этих двух экранов — раздел «01 · После оплаты» в [карте](./index.html).

**Урок 1** — название **«Кисуль, добро пожаловать!»**. Сначала реальное видео Ксюши, под ним текст из карточки Урока 1. Видеосценарий рядом с карточкой нужен **Ксюше для записи**, не вставляется дополнительным уроком. Короткая философия уже включена внутрь этого видео и описания.

**Урок 2** — название **«Кисуль, не пропусти этот шаг!»**. Только объяснение анкеты, её важности и 2 способа перехода в Telegram (крупная кнопка + обычная ссылка). **Анкета не в GetCourse.** До её прохождения питание закрыто.

## После анкеты: один выбранный рацион

Связать Telegram-профиль с пользователем, который успешно купил продукт, и сохранить результат по утверждённой методике. Выдавать **только одну** из четырёх веток 1400 / 1600 / 1800 / 2000 ккал.

**Урок 3** для каждого варианта расположен в карте в разделе «04 · План недели и питание», назван «Урок 3 · Питание на неделю · XXXX ккал». Готовый текст включает:
- что означают КБЖУ;
- как читать рецепты и распределять 3 основных приёма + перекус;
- когда продукты взвешивать сырыми/сухими;
- как делить общий готовый объём по количеству одинаковых порций;
- PDF меню на дни 1–7;
- PDF покупок на дни 1–7;
- расписание и переход к Дню 1.

**Не создавать отдельную страницу для КБЖУ, покупок или инструкции по еде.** Всё уже есть в Уроке 3.

## Дни 1–14: рецепты и видео

В каждой ветке последовательно идут 14 дневных уроков; первые 7 открываются сразу после анкеты, следующие 7 — в первую пятницу. Названия и поля — в [CSV-реестре](./GC_СТРУКТУРА_УРОКОВ.csv).

Для каждого дня собрать:
1. Название из CSV и актуальную подводку Ксюши из раздела «05 · Дни марафона» в карте.
2. **Четыре** рецепта (завтрак, обед, ужин, перекус) строго из PDF **своего** рациона. Фото/ингредиенты/КБЖУ не менять.
3. Видео по расписанию либо текст дня отдыха.
4. Кнопку «Назад к моей неделе».

**Видео по новой схеме:** Пн зарядка, Вт осанка, Чт растяжка, Пт зарядка. Это 4 зарядки, 2 осанки, 2 растяжки за марафон.

**На День 8 или внутри закреплённого блока второй недели:** прикрепить PDF меню и продукты дней 8–14 выбранной калорийности. Файлы должны открыться в пятницу первой недели. Отдельный обязательный урок перед Днём 8 не нужен.

## Где брать файлы

- **Новые тексты и кнопки:** [course-map](./index.html) и [полный текстовый дубль](./content.md).
- **Названия, даты доступа, видео и типы блоков:** [CSV](./GC_СТРУКТУРА_УРОКОВ.csv).
- **Оригинальные рецепты, фотографии, граммовки и PDF:** из комплекта исходных четырёх меню и архива импорта.
- **Изображения Ксюши:** только её исходные фотографии; сторонние/сгенерированные лица исключить.
- **Видео:** реальные файлы Ксюши, ожидаются отдельно.

**Внимание:** прежние `lessons/00_intro_*.html`, `*_week1_intro.html` и старые подводки в 56 дневных HTML делались под предыдущую схему. Они **не являются актуальным текстом**. Для рецептов дневные HTML можно использовать как источник структуры и исходных фото, но подводку нужно заменить текстом из открытой карты. Старый ZIP **не использовать как единый источник новой логики**.

## Контроль перед публикацией

- [ ] Урок 2 содержит кнопку и запасную ссылку в Telegram.
- [ ] Без бота Урок 3, PDF и дни действительно закрыты.
- [ ] После бота отображается **один** Урок 3 нужной калорийности и все семь дней первой недели.
- [ ] В Уроке 3 две PDF и вся подробная инструкция.
- [ ] В каждом дне три основных приёма и перекус.
- [ ] Дневные видео по ПН/ВТ/ЧТ/ПТ сопоставлены с новым расписанием.
- [ ] Вторая неделя с PDF открывается в первую пятницу.
- [ ] Срок доступа 14+7 дней.
- [ ] Проверены email, оплата, кнопки, мобильное отображение, запреты на чужие PDF.
